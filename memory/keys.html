Подготовка раунда

Настройки

Поиск → проверка без подсказок → перестановки. Все ответы раскрываются только в конце.

⌕

Поиск ключей

Ребёнок указывает коробку, педагог нажимает. После просмотра она закрывается.

Следующий ключ не появится в коробке, где уже находили ключ.

⌖

Проверка памяти

Отметь коробки с ключами.

Отмечено: 0 / 3

Ответ сохраняется без проверки. Правильные места покажем только в конце всего раунда.

⇄

Начинаем перемещения

Следи за коробками с ключами. Содержимое остаётся внутри.

⇄

Следи за коробками

Коробки действительно меняются местами, но ключи остаются внутри своих коробок.

Во время перемещения выбирать коробки нельзя.
