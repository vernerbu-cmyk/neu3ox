# Проверки тренажёров памяти

- `node --test tests/*.test.cjs` — все проверки логики, включая хронологию, эры, сравнения событий и задания «Изложения».
- `python3 tests/memory_games_browser.py` — восстановление «Цепочки» после ошибки, годы до нашей эры, события одного года и однократное начисление награды в «Истории».
- `python3 tests/memory_regressions_browser.py` — оценка ответов в «Двойной задаче» и «Отражении», стартовая длина и реверс «Саймона», вопросы по показанным фактам «Новостей», однозначность заданий «Подземелья», генерация и прохождение связанных замков «Взлома». Проверяет все входные экраны при ширине 320, 390 и 1280 пикселей, игровые экраны «Отражения» и «Взлома» на телефоне. Нужны Python Playwright и `/usr/bin/chromium`.

- `node --test tests/retelling.test.cjs` — сопоставление слов, доступность полного зачёта для всех планов, область всех 390 вопросов, состав сокращённых упражнений и проверка черновика пересказа.
- `python3 tests/retelling_browser.py` — пользовательские сценарии в браузере, включая кнопки «Дальше», сокращённые вопросы и опоры, ввод пересказа и узкий экран. Нужны Python Playwright и Chromium по пути `/usr/bin/chromium`; в подготовленной облачной среде они уже установлены.

При изменении текста или порядка вопросов в `memory/texts.js` обновляйте соответствующую запись `memory/statement-scopes.js`: номера абзацев начинаются с единицы. Отмечайте абзац, в котором находится ответ на вопрос, а не первое вхождение отдельного слова из ответа.
