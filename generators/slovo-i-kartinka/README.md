# Слово и картинка

Полный исходный код генератора с иллюстрациями.

## Запуск

Распакуйте архив. Откройте терминал в папке slovo-i-kartinka и выполните:

    python -m http.server 8000

Откройте http://localhost:8000 в браузере. Если команда python не найдена, попробуйте python3.
Сборка, установка библиотек и ключи API не нужны.

## Файлы

- index.html — интерфейс и стили.
- app.js — генератор, слоги, три шага чтения, вопросы, ручной выбор картинок, сохранение листов.
- stories.js — 100 сюжетов на 10 тем, три варианта длины и вопросы.
- illustrations/ — полный набор из 161 иллюстрации (общие листы рисунков и отдельное дерево).

В app.js словарь groups связывает формы слов с рисунками. illustrationMap задаёт файл и границы каждого рисунка. splitSyllables делит слова по принятому в генераторе правилу для обучения чтению.

## Сохранение

Подборки хранятся в localStorage текущего браузера и адреса сайта. Переносите их кнопками «Выгрузить подборку» и «Загрузить подборку».

## Печать

«Печать / PDF» открывает системное окно печати. Для PDF выберите «Сохранить как PDF».

## Размещение на сайте

Загрузите содержимое папки на статический хостинг, сохраняя структуру файлов. Серверная часть не нужна.

## Два рассказа на A4 и крупный шрифт

В боковой панели выберите «Рассказов на листе → Два рассказа». Для второго текста доступны своя тема, уровень и сюжет, а также свой текст. Размер шрифта регулируется от 14 до 72 px; кнопка «Подогнать шрифт на один A4» уменьшает его при необходимости. Если содержимое всё же не помещается, появляется предупреждение; печать сохраняет весь текст, продолжая его на следующих страницах. Пара рассказов сохраняется вместе с листом.

## Встраивание в NeuroX

Расположение в общем проекте: `generators/slovo-i-kartinka/index.html`.
В `../index.html` (главное меню генераторов) добавлена карточка №15,
в `../../assets/menu-data.js` добавлен пункт общего меню.
`icon.svg` — собственная векторная иконка, `neurox-style.css` — оформление,
`neurox-ui.js` — кнопка переключения общей темы NeuroX.
Все сюжетные данные, иллюстрации, выбор картинок, печать и работа с сохранёнными листами сохранены из исходного архива.
Важно: исходные иллюстрации — PNG-атласы, показанные внутри SVG-обёрток;
они не превращены в векторные рисунки (во избежание потери их вида).
