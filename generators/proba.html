Справка

Корректурная проба — тест на устойчивость внимания. Просматривайте поле и отмечайте заданные символы.

Режим. «Буквы» — поле из букв, «Значки» — из геометрических символов.

Что искать. Отметьте символы в палитре. Ниже для каждого символа выберите способ пометки — например, А → кружок, Б → квадрат.

Интерактив. Клик по клетке ставит пометку по правилу для символа в этой клетке. Повторный клик снимает.

Печать. При печати сверху листа появляется задание и поля для Ф.И.О. и даты.
