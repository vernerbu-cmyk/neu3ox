# NeuroX «Верю — не верю» — Beta 6

Новые настройки фраз: **ЗАГЛАВНЫМИ** и **По слогам (по правилам переноса)**. Переключатели независимые, сохраняются между сеансами; менять можно со стартового экрана или через кнопку «Аа» во время игры. Переносы для всех слов из текущих 60 фраз проверены вручную, словарь внутри `index.html` и отдельно в `reading-transfers.json`; для новых слов предусмотрен осторожный автоматический вариант. Односложные и не допускающие переноса слова остаются целыми.

**Важно:** деление по правилам переноса и фонетическое слогоделение не всегда совпадают.

60 прежних заданий и иллюстраций WebP сохранены без дополнительного сжатия или уменьшения разрешения. Картинка открывается только после ответа.

Для интернета загрузите все файлы (`index.html`, `questions.js`, `images/`), не меняя их относительного расположения.

Вариант в одном HTML можно собрать командой `python3 build_one_file.py`.
